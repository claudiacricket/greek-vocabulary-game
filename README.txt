Greek Vocabulary Study Game — words 1–840

Open index.html locally to test.

ONLINE HOSTING (FREE)
This folder is ready for static hosting. GitHub Pages is a simple option:
1. Create a GitHub repository.
2. Upload all files and the assets folder.
3. In repository Settings > Pages, choose "Deploy from a branch".
4. Choose the main branch and /(root), then Save.
5. GitHub will give you an HTTPS web address. Anyone with that URL can open it in Chrome/Safari on an iPad without installing anything.

Files:
- index.html: complete app
- assets/: 840 cropped vocabulary images
- vocab_1_840.csv / .json: editable vocabulary data
- .nojekyll: makes GitHub Pages serve this as a plain static site

Modes:
- Flashcards: picture -> Greek, audio, optional English
- Match: picture <-> Greek; numbers intentionally hidden during play
- Listen: hear Greek and choose the picture
- Spell: hear Greek and type it; includes an onscreen Greek keyboard
